# Nawahub Static

Official static website for Nawah, designed to present projects, services, educational content, and Web3 ecosystem positioning in a modern and professional manner.

## Overview

Nawahub Static is a lightweight static web project created to introduce Nawah as a digital identity, showcase its services and initiatives, and provide a clean, scalable foundation for future expansion.

The project is intended to serve as:
- a public landing page
- a brand presentation website
- a Web3 education and awareness portal
- a foundation for future digital products and business services

## Domain

Official domain:
- https://alnawah.net

## Project Status

Status: In active development

Current focus includes:
- refining the site structure
- improving homepage content
- unifying page templates
- preparing the project for production deployment
- documenting the project and technical setup
