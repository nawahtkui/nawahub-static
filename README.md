## Overview

Nawahub Static is a lightweight front-end project designed to introduce Nawah as a digital identity and present its initiatives in a clear, modern, and professional format. The project serves as the official public-facing landing website and acts as a foundation for future expansion into broader digital products and services.

This project is intended to support:
- brand recognition
- public awareness
- service and project presentation
- Web3 education and ecosystem communication
- scalable future growth
